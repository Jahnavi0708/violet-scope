# SCOPE Ascend

Create a stunning, premium, modern website for SCOPE Club based on the provided AWS Cloud Trek 2026 problem statement.

The website must feel like a high-end developer/community portfolio, not a basic college website.

CORE DESIGN DIRECTION

Theme:

Primary background: deep black / near-black

Accent: electric purple / violet

Secondary accent: subtle lavender

Text: white and soft gray

Use purple glow effects sparingly

Premium dark UI

Modern glassmorphism elements

Soft gradients

Subtle borders

Smooth animations

Strong visual hierarchy

Overall feeling:
"Elite developer community + futuristic technology + premium portfolio."

Do NOT make it look like a generic template.

Make the design visually impressive from the first screen.

HTML
